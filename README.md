# 🚌 Bus Booking System

A full-stack **Bus Booking System** built using the **MERN Stack**
(MongoDB, Express.js, React.js, Node.js).

🌐 **Live Demo:** https://www.thesmartbu.me/

---

## ✨ Features

### 👤 User
- Login / Register (JWT Authentication)
- View available buses
- Book bus tickets
- View booking history

### 🧑‍💼 Admin
- Add & manage buses
- View all bookings
- Manage routes

---

## 🛠 Tech Stack

### Frontend
- React.js
- Axios
- React Router
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
